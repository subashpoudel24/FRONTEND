```

│   ├── blogs/          # Blog posts
```

## 🔧 SEO Configuration

### Domain Setup
Update the following files with your actual domain:
- `pages/index.js` - Update canonical URLs
- `components/SEO.js` - Update siteUrl
- `public/sitemap.xml` - Update domain URLs
- `scripts/generate-sitemap.js` - Update baseUrl

### Google Search Console
1. Verify ownership of subashpoudel.com
2. Submit sitemap: `https://subashpoudel.com/sitemap.xml`
3. Monitor search performance

## 🚀 Deployment

### Build and Deploy
```bash
npm run build    # Builds the app and generates sitemap
npm start        # Starts production server
```

### Vercel Deployment
1. Connect your GitHub repository to Vercel
2. Set environment variables if needed
3. Deploy with automatic SSL and CDN
